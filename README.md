# Кубики и виды — 3D-конструктор по математике (5 класс)

Интерактивное наглядное пособие для урока математики по теме **«Пространственные фигуры из единичных кубов и их виды со сторон»**.

## Краткая памятка для учителя

1. **Как открыть:** перейдите по ссылке сайта (или дважды нажмите на файл `index.html`) — программа сразу откроется в браузере, ничего устанавливать не нужно.
2. **Как строить и удалять кубики:**
   - **Добавить куб** — нажмите левой кнопкой мыши (или коснитесь пальцем на интерактивной доске) на любую клетку площадки или на сторону уже стоящего кубика.
   - **Удалить куб** — нажмите на него правой кнопкой мыши. На интерактивной доске удобнее переключиться вверху на кнопку **«Ластик»** и просто касаться ненужных кубиков.
   - **Выбрать цвет** — нажмите на один из четырёх цветных квадратов в верхней панели (удобно выделять этажи или спрятанные кубики).
   - **Ошиблись?** — нажмите **«Отменить»** (вернёт шаг назад) или **«Очистить»** (уберёт все кубики).
3. **Готовые фигуры:** в списке **«Готовые фигуры…»** вверху есть 6 примеров («Лесенка», «Башня», «Уголок», «Арка», «Мостик», «Секретный куб») — можно открыть любой за один клик.
4. **Как крутить и смотреть со всех сторон:**
   - Зажмите левую кнопку мыши (или проведите пальцем) по пустому фону и двигайте — фигура будет вращаться. Колёсико мыши приближает и отдаляет.
   - Кнопки внизу (**«Изометрия (3D)»**, **«Вид спереди»**, **«Вид сверху»**, **«Вид сбоку»**) плавно поворачивают фигуру точно нужной стороной, чтобы дети видели, как объёмная фигура превращается в плоскую схему.
5. **Панель «Виды со сторон» справа:**
   - Показывает три проекции сразу по мере сборки.
   - Нажмите **«Скрыть проекции»**, чтобы закрыть ответы шторкой, обсудить фигуру с классом, а затем нажать **«Показать проекции»** для проверки.
6. **Объём и размеры:** в левом нижнем углу автоматически считается количество кубиков (**«Объём фигуры»**) и её габариты (длина × ширина × высота).
